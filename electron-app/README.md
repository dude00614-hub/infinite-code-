# Infinite Code - Desktop App

A cross-platform desktop app for Infinite Code built with Electron.

## Quick Start

1. **Install Node.js** from https://nodejs.org (LTS version)
2. Open this folder in terminal
3. Run:

```bash
npm install
npm start
```

## Build Installer

To build a distributable installer (.exe, .dmg, or .AppImage):

```bash
npm run dist
```

The installer will be in the `dist/` folder.
